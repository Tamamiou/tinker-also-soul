# Tinker Also Soul (匠魂也是魂)

让匠魂的盔甲在史诗战斗（Epic Fight）中正确显示纹理，并内置了武器兼容数据包。

## 🛠️ 支持的版本
- Minecraft: **1.21.1**
- 模组加载器: **NeoForge**

## ✨ 功能特性
- 动态烘焙匠魂盔甲纹理，史诗战斗模式下不再显示为原版模型或紫黑方块。
- 内置匠魂与史诗战斗的武器兼容数据包，开箱即用。

## 📦 必需的前置模组
本模组**必须**与以下模组一同安装。请前往它们的发布页面（Releases / Files）下载对应的 `.jar` 文件：
- [Tinkers' Construct (匠魂)](https://github.com/zhuchuovo/TinkersConstruct-1.21.1)
- [Mantle (地幔)](https://github.com/zhuchuovo/Mantle-1.21.1)
- [Epic Fight (史诗战斗)](https://github.com/Antikythera-Studios/epicfight)

## 🚀 安装指南
1. 确保你已安装 Minecraft 1.21.1 和 NeoForge。
2. 将本模组（`tinker_also_soul-x.x.x.jar`）以及上述所有前置模组的 `.jar` 文件，一同放入游戏根目录下的 `mods` 文件夹中。
3. 启动游戏，享受修复后的盔甲渲染与武器兼容！
